CALCULATOR APP - HOW TO PUT IT ON GITHUB AND YOUR PHONE

1. On github.com, create a new repository. A plain name like "calculator" is best.
2. Upload everything in this folder (index.html, manifest.json, sw.js and the icons folder). Keep the same file names and folders.
3. In the repository, open Settings, then Pages. Under Branch, choose "main" and the "/ (root)" folder, then Save.
4. Wait a minute or two. GitHub shows your web address, which looks like https://yourname.github.io/calculator/
5. Open that address on your phone.
   iPhone (Safari): tap Share, then Add to Home Screen.
   Android (Chrome): tap the menu, then Install app or Add to Home screen.
6. Open it from your home screen. The icon shows for about 2 seconds, then the calculator appears.

Moving over passwords from a test version: passwords are saved per web address, so the new address starts empty. In the old version use the gear icon, then Export / Import and copy the text. In the new app, set up first, then use Import.

Updating later: replace index.html on GitHub. Open the app twice to see the change.
